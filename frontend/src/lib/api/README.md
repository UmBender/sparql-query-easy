# api

Typed client for the Ktor API (FE-043). Requests use same-origin paths
(`/api`, `/health`); the Vite dev server proxies them to Ktor on port 8080.

- `client.ts`: one method per route; resolves to the `data` of a
  `DataResponse` or rejects with `ApiError` (`bad-request` 400, `not-found`
  404, `upstream` 502, `server`, `network`, `aborted`, `unexpected`).
  Response types come from `schema.d.ts`; request bodies from the domain.
- `queries.ts`: TanStack Query cache keyed by request payload (`fetchQuery`,
  `staleTime` 5 min) and `createDebouncedRequest` for typing-driven calls.
- `openapi.json`: snapshot of Ktor's `/openapi.json`, kept equal by the Kotlin
  test `FrontendOpenApiSnapshotTest` (refresh with `UPDATE_FRONTEND_OPENAPI=1`).
- `schema.d.ts`: generated by `npm run api:types` (openapi-typescript 7.13.0
  through npx); `api-contract.spec.ts` checks it matches the snapshot.
